Your LLM bill has a leak.
It's the noise in your prompts.

Tool outputs, build logs, JSON dumps, pasted HTML — every token of noise costs you money. token-cost-optimizer is a transparent proxy that strips it before it reaches the API. You change one line of code.

Get it on GitHub How it works

Open source (MIT). Self-host free on Cloudflare Workers. No account, no signup.

One line to integrate

Point your OpenAI-compatible client at the gateway instead of the API. Everything else stays the same — same SDK, same key, same models.

# before
client = OpenAI(base_url="https://api.openai.com/v1", ...)

# after
client = OpenAI(base_url="https://your-gateway.workers.dev/v1", ...)

The gateway compresses the bulky parts of each request, forwards the rest untouched, and reports tokens saved in the response headers. Your API key is forwarded, never stored — or self-host and keep everything on your own infrastructure.

What it actually saves

Measured on real inputs, not benchmarks designed to impress:

InputSaved
Python source → signature skeleton91.9%
Terminal build log → denoised63.5%
JSON API response → schema + sample70–98%
HTML page → readable content90–98%

Ranges depend on how noisy your input is. Tight prompts have nothing to strip — the gateway passes them through and tells you so.

What it won't do

  • Rewrite your prompts or change their meaning. Noise removal only.
  • Replace the full Python toolkit's AST code analysis — the gateway does a lighter heuristic pass.
  • Cache anything. This shrinks what you send; it doesn't remember it.

Two ways to use it

Gateway — drop-in proxy for OpenAI-compatible APIs. Deploy the Worker yourself in about ten minutes, free tier is plenty.

CLI toolkit — seven small Python scripts for offline use. Pipe a file through tco and see the savings before you send anything.
