Token Kit demo

Estimate tokens and convert JSON, CSV, or HTML tables to Markdown tables, in your browser.

Approximate, not an official tokenizer. Token counts use a public formula: CJK characters count as 1 token each, non-CJK characters count as about 4 characters per token. Do not use this count as an official tokenizer result for any model.

Privacy: everything on this page runs in your browser. Nothing you type is sent to a server, no login, no API key. To call the real API, use the RapidAPI links below.

Formula, same as the API: tokens = round(CJK + non-CJK / 4). CJK means characters in U+2E80-U+9FFF, U+3400-U+4DBF, or U+F900-U+FAFF.
